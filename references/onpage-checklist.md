# On-Page SEO Checklist

## Title Tag
- [ ] 30-60 characters
- [ ] Primary keyword near the beginning
- [ ] Brand name at the end (separated by | or —)
- [ ] Unique per page
- [ ] Compelling for click-through

## Meta Description
- [ ] 50-160 characters
- [ ] Contains primary keyword naturally
- [ ] Includes call-to-action or value proposition
- [ ] Unique per page
- [ ] Matches page content

## URL Structure
- [ ] Short and descriptive (3-5 words max)
- [ ] Contains primary keyword
- [ ] Uses hyphens (not underscores)
- [ ] Lowercase only
- [ ] No special characters or parameters

## Headings
- [ ] Single H1 per page with primary keyword
- [ ] H2s for main sections (2-6 per page)
- [ ] H3s for subsections
- [ ] Logical hierarchy (no skipping levels)
- [ ] Keywords distributed naturally across headings

## Content
- [ ] Minimum 300 words for standard pages
- [ ] Minimum 1000 words for pillar/blog content
- [ ] Primary keyword in first 100 words
- [ ] Keyword density 1-2% (natural usage)
- [ ] LSI keywords included (related terms)
- [ ] Internal links to related pages (3-5 per page)
- [ ] External links to authoritative sources (1-2 per page)
- [ ] Content matches search intent

## Images
- [ ] Descriptive alt text with keyword where natural
- [ ] Compressed file size (<200KB for web)
- [ ] Descriptive file names (hematologista-consulta.jpg)
- [ ] Width/height attributes set (prevents CLS)
- [ ] loading="lazy" for below-fold images
- [ ] WebP format preferred

## Technical On-Page
- [ ] Canonical URL set
- [ ] Open Graph tags (title, description, image, type)
- [ ] Twitter Card meta tags
- [ ] Structured data (Schema.org JSON-LD)
- [ ] Language attribute on <html>
- [ ] Mobile-responsive viewport meta
- [ ] Fast loading (<3s LCP)
- [ ] No render-blocking resources
- [ ] Preconnect to external domains

## Internal Linking
- [ ] Descriptive anchor text (not "click here")
- [ ] Links to related content
- [ ] Breadcrumb navigation
- [ ] Sitemap.xml up to date
- [ ] No broken internal links

## User Experience Signals
- [ ] Above-fold content is meaningful
- [ ] Clear CTA visible without scrolling
- [ ] Mobile-friendly tap targets (48px min)
- [ ] No intrusive interstitials
- [ ] Fast interaction response (<100ms)
- [ ] Accessible (WCAG 2.1 AA)

## Local SEO (for medical/service businesses)
- [ ] NAP (Name, Address, Phone) consistent across site
- [ ] City/region in title tag
- [ ] Google My Business linked
- [ ] LocalBusiness/Physician schema
- [ ] Embedded Google Maps
- [ ] Local keywords in content
- [ ] Service area pages if multiple locations
